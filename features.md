# GenMash Software Solutions – Website Features & Structure

## 1. Website Overview
This website is a professional software company website for GenMash Software Solutions.  
The goal of the website is:
- Showcase company services
- Display portfolio and case studies
- Generate leads via contact and quote forms
- Build brand credibility
- Allow admin to manage content (portfolio, blog, testimonials, etc.)
